Group-to-Role Mappings

A user gets every role their OIDC groups map to, and those replace the role set on the user. With no matching mapping, the user's own role applies. Groups are as of each user's last login.

A role is a set of permissions. The four built-in roles can't be changed. Custom roles can be assigned to users, mapped from groups, and used to cap API tokens.
